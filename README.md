# Мониторинг рабочих мест

Простой веб-сервис для класса на 30 компьютеров: студенты регистрируются по QR-коду,
преподаватель в реальном времени видит, какие места заняты и где проблемы.

Нужен только Python 3.9+ (без дополнительных пакетов). Данные — в `data.db` (SQLite).

## Запуск

Двойной клик по `start.bat` (или `py server.py`). В консоли появится адрес, например
`http://192.168.1.25:8080`.

- `/teacher` — экран преподавателя (пароль по умолчанию `teacher`, смените в `config.json`).
- `/qr` — страница печати QR-кодов для 30 мест. Каждый код ведёт на `/form?pc=N`.
- `/form` — форма студента (номер места подставляется из QR).
- `/export.csv` — весь журнал (открывается в Excel).

Телефоны студентов должны быть в той же сети (Wi‑Fi), что и компьютер с сервером.
При первом запуске Windows спросит про брандмауэр — разрешите доступ в частной сети.

## Экран преподавателя

- Зелёное место — студент зарегистрировался на текущей паре.
- Жёлтое — вы кликом отметили «место занято, но студент не зарегистрировался».
- Красное мигающее + баннер сверху + мигающий заголовок вкладки + звуковой сигнал
  (включите кнопкой «Звук») — студент сообщил о проблеме. Кнопка «Решено» закрывает её.
- «Новая пара» — очищает схему мест (журнал сохраняется, нерешённые проблемы остаются).
- Экран обновляется каждые 3 секунды.

## Где хранятся данные

Сервер запускается на компьютере преподавателя, и все регистрации лежат только там —
в файле `data.db` рядом с `server.py`. В репозиторий не попадают ни база, ни `config.json`
(с паролем). Для резервной копии достаточно скопировать `data.db`.

## Рассадка

Схема на экране преподавателя повторяет аудиторию: стол преподавателя сверху,
4 вертикальных ряда (7 + 7 + 7 + 9 мест), проходы между 1–2 и 3–4 рядами, стол перед 2–3 рядами.
Номера мест идут «змейкой»: ряд 1 — 1→7 от стола назад, ряд 2 — 8→14 обратно к столу,
ряд 3 — 15→21 от стола назад, ряд 4 — 22→30 к столу. Стол — у мест 14 и 15. Изменить нумерацию или ряды — блок `layout` в `config.json`.

## config.json

Создаётся при первом запуске: порт, рассадка (`layout`), пароль, название
аудитории, расписание звонков (по нему в форме заранее выбирается текущая пара) и
`base_url` — если автоматически определённый IP неверный (например, адрес виртуального
адаптера), укажите здесь правильный, например `"http://192.168.1.25:8080"`.
После изменения перезапустите сервер.
